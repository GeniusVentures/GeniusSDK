<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| C caller → SDK init | Untrusted dev_config JSON string crosses ABI boundary; parsed by RapidJSON |
| C caller → SDK init | Untrusted eth_private_key / mnemonic C-strings; passed to GeniusNode for wallet ops |
| SDK init → GeniusNode::New | DevConfig_st + AccountSource variant — internal C++ boundary, trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | dev_config JSON string from caller | mitigate | RapidJSON parse failure returns nullptr; ParseDevConfig validates all required fields (Address, Cut, TokenValue, TokenID) |
| T-01-02 | Denial of Service | Malformed/oversized JSON | mitigate | RapidJSON handles parse errors gracefully; no allocation based on untrusted size without parse guard |
| T-01-03 | Information Disclosure | Error messages in SPDLOG_ERROR | accept | Error messages contain field names (not values); no key material logged; acceptable for SDK diagnostic output |
| T-01-04 | Elevation of Privilege | eth_private_key / mnemonic C-string lifetime | mitigate | D-06: captured by value (std::string) before constructing AccountSource; prevents use-after-free if caller stack unwinds |
| T-01-05 | Spoofing | base_path pointing to attacker-controlled filesystem | accept | base_path is a caller-provided filesystem path; network_config.json / sgns_config.json validation is the engine's responsibility (GeniusNode), not the SDK's |
</threat_model>
